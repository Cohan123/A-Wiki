# Start

Willkommen im internen Firmen-Wiki.

## ![image.png](content/uploads/start/image.png){width=821}

Auf dem Startbildschirm befindet sich die Gesamtübersicht  über das Wiki, eine **Suchleiste** zur Artikelsuche und ein Button zum direkten Erstellen eines **neuen Artikels. **Bei der Suchfunktion handelt es sich um eine Volltextsuche.

Im **oberen Dashboard** befinden sich folgende Schaltflächen:

- **Mein Konto** -> hier lässt sich mein Name & Passwort ändern. Der Name wird beim Erstellen von Artikeln automatisch als Verantwortlicher eingetragen. Daher sollten zur Transparenz hier bitte auch Reale Klarnamen verwendet werden.
- **Vorschläge** -> hier werden meine Änderungs- und Löschvorschläge von Artikeln, die bei einem Administrator auf Freigabe warten, angezeigt.
- **Abmelden **-> hier logge ich mich als Benutzer aus dem Wiki aus
- **Dunkel **-> Darkmode an / aus
- **Optionen **-> Link für Wiki zum teilen des Wikis / Drucken: Ausdrucken eines Arikels / der aktuellen Ansicht

Im Linken Dashboard befinden sich folgende Schaltflächen:

- **Startseite** -> Rückkehr auf die Startseite von jedem Punkt des Wikis
- **Produkte** -> Produktverwaltung, hier können alle angelegten Produkte, entsprechend Ihrer Kategorisierung, eingesehen und bearbeitet werden. Hier können auch neue Produkte über den Button „Neue Produkte“ angelegt werden, wenn diese benötig werden.
- **Kategorien **-> Hier werden alle Artikel, die für das Wiki erstellt wurden unter ihren jeweiligen Kategorien und Produktgruppen sortiert angezeigt.
